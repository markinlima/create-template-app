# Language

- **Always write in English** — code, comments, commit messages, scripts,
  and documentation must all be in English, regardless of the language
  used in the conversation. This explicitly includes `README.md`,
  `AGENTS.md`, `docs/*.md`, and `.agents/memory/*.md` — every project
  document, not just code.
- **Don't follow inconsistent docs as precedent.** If you find an
  existing document written in another language, that's drift from this
  rule, not an exception to it — write new content in English regardless,
  and fix the old document if you can.
- **User-facing text must be in Brazilian Portuguese.** Any message shown
  to the end user — UI copy, error messages, notifications, emails, etc. —
  must be written in Brazilian Portuguese (pt-BR), even though the
  surrounding code, comments, and identifiers stay in English.
